01 / 전체 구조

크게 보고, 사업을 보고, 한 건씩 봅니다

갈래를 누르면 자료의 뜻과 출처, 남은 제약을 자세히 볼 수 있습니다.

● 확보◐ 제약 있음○ 미수집
세 칸을 읽는 법   제공처: 자료가 있는 출처를 알고 있음 · 수집: 우리 저장소에 자료가 있음 · 화면: 보여줄 자리의 파일이 있음.
숫자와 상태의 판정 기준

갈래의 ‘확보’는 필요한 자료가 있고 적어 둔 제약이 없다는 뜻입니다. ‘제약 있음’은 범위·연결·활용에 한계가 남았다는 뜻입니다. 모든 항목을 검증했다는 의미는 아닙니다.

‘제공처 확인’만으로 자료 전체의 공개 여부를 판단할 수 없습니다. 열린재정은 목록·명세를 받은 상태이며, 실제 수치 전수를 확보한 것으로 세지 않습니다.

‘화면 있음’은 지정된 화면용 파일이 있다는 뜻입니다. 그 갈래의 모든 칸이 구현되었거나 사업·계약이 서로 연결됐다는 뜻은 아닙니다. 화면 반영 기준과 파일 위치는 각 갈래 안에서 확인할 수 있습니다.

활용 상태는 현재 프로젝트 기준입니다. ‘미수집’은 세상에 자료가 없다는 뜻이 아닙니다. ‘최신 확인’은 마지막 조사에서 확인한 연도이며, 제공처의 현재 상태와 다를 수 있습니다. API는 자료를 자동으로 받는 통로입니다.

자료 수집 후 python scripts/build_datamap.py를 실행합니다. 자료 위치를 훑어 상태를 다시 매기고, 기존 데이터 지도의 기록과 비교합니다. 브라우저 새로고침만으로 원본을 수집하지는 않습니다.

별도 이력 파일 없이 site/datamap.html 안에 마지막 상태와 변경 기록을 보존합니다. 동일한 자료로 다시 만들면 기록이 늘어나지 않습니다. 생성물이 충돌하면 공유 저장소의 최신 데이터 지도를 복원한 뒤 다시 만듭니다.

새 소스의 저장 위치는 scripts/build_datamap.py의 받을자리·낼자리에 등록합니다. 등록하지 않은 새 자료도 ‘갈래에 아직 연결하지 않은 자료’의 파일 변화로 잡힙니다.
