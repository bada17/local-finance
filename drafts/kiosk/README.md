# 전국 무인 회수기 계약 화면 시안

숫자 확정 전, 화면과 탐색 흐름을 검토하기 위한 로컬 시안입니다.

## 열기

저장소 루트에서 다음 명령을 실행하고 출력되는 주소를 엽니다.

```powershell
node drafts/kiosk/serve.mjs
```

기본 주소는 `http://127.0.0.1:4173`입니다. HTML 파일을 직접 더블 클릭하면 브라우저의 로컬 파일 제한 때문에 자료를 읽지 못할 수 있습니다. 설치·빌드·외부 서비스 연결은 필요하지 않습니다. 서버는 이 폴더만 읽어서 제공합니다.

## 화면에서 확인할 것

- 전국 요약: 계약 건수, 원 단위 합계와 억 원 표시, 코드로 중복 제거한 지자체 수.
- 계약한 해마다 설치와 유지관리의 나란한 막대. 금액·건수 전환 및 해 선택.
- 지역별: 전국 → 시도 → 지자체 → 계약 목록. 지도와 목록 모두 클릭 가능.
- 업체별: 업체묶음별 금액과 현재 조건 금액 합계에 대한 몫 → 계약한 지자체 → 해당 업체의 계약. 지자체의 모든 업체 계약으로 전환 가능.
- 검색에 `시흥`을 입력하고 지역별 → 경기 → 경기도 시흥시를 누르면 예시를 볼 수 있습니다.
- ‘놓쳤을 수 있음’은 처음에 제외합니다. 켜면 모든 화면에 적용하며 포함 사실을 표시합니다.
- 계약한 해·갈래·품목·검색은 모든 화면과 상세에 적용합니다. 지역 선택은 지역별·계약 목록 화면에 적용합니다.

## 자료와 경계

계약 숫자는 모두 `data.json`의 `rows`에서 브라우저가 계산합니다. `meta.건수`나 별도 고정 합계를 사용하지 않습니다. 자료 기간은 `meta.설명`에서 읽고 `meta.주의`를 화면에서 그대로 확인할 수 있습니다. 원자료는 수정하지 않았습니다.

계약한 해는 지출 연도가 아닙니다. 유지관리는 전년도 말에 다음 해치를 계약하기도 합니다. 마지막 해의 부분 수록 기간을 화면에 표시합니다. 계약 건수를 회수기 대수로 표현하지 않으며 수의계약 비율을 계산하거나 강조하지 않습니다.

업체묶음은 자료의 값을 그대로 사용하며 계열사 묶음이나 검증된 동일 법인으로 해석하지 않습니다. 금액 몫은 자료에 잡힌 계약의 비중이며 전체 시장점유율이 아닙니다.

`map.json`은 `data/boundary/`의 시도·시군구 Parquet에서 만든 SVG 경로입니다. 출처는 저장소의 `scripts/build_shapes.py`에 기록된 vuski/admdongkor, CC BY 4.0입니다. 경계는 2026-07-01, 인천 옛 구는 2026-04-01 경계도 사용합니다. 계약 금액은 지도 파일에 저장하지 않습니다.

전국 지도는 본토·제주 중심으로 일부 도서를 생략합니다. 원자료의 ‘전남광주’는 별도 목록으로 보존하고 겹치는 지리에 억지로 배정하지 않습니다. 경계에 연결되지 않은 지자체는 `map.json`의 `unmatched` 및 화면 설명에서 확인할 수 있으며 목록과 합계에 포함합니다. 지도 미로딩 시에도 목록은 동작합니다.

경계 파일을 다시 만들 때만 Python과 `pyarrow`가 필요합니다.

```powershell
python drafts/kiosk/build_map.py
```

## 확인

```powershell
node drafts/kiosk/model.test.mjs
node --check drafts/kiosk/app.mjs
```

검증은 상태 제외·포함, 금액·지자체 합계, 복합 필터, 시흥시, 업체별 금액 합계 일치, 연도별 합계 일치, 빈 결과, 지자체 이름 변경 시 코드 중복 제거를 확인합니다.

화면 이미지는 `preview-desktop.png`, `preview-mobile.png`, `preview-regions.png`, `preview-siheung.png`에 있습니다. 시안 화면을 캡처한 이미지이므로 자료나 화면을 바꾼 뒤에는 다시 캡처해야 합니다.

작성 파일과 캡처는 모두 `drafts/kiosk/` 안에 있습니다. 공개 사이트로 배포하거나 `site/`를 수정하지 않았습니다.
